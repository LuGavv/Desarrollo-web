🧩 Pokémon 3D Cards

¡Bienvenido/a a Pokémon 3D Cards!
Este proyecto es una aplicación web interactiva que utiliza la PokéAPI para mostrar información de distintos Pokémon en forma de cartas dinámicas, con la posibilidad de invocarlos en 3D y ver sus modelos de manera visual e inmersiva.

🚀 Descripción

La aplicación permite explorar distintos Pokémon de una manera divertida y visual.
Cada carta muestra el nombre, la imagen y los atributos principales del Pokémon.
Además, cuenta con un botón de “Invocar”, que al activarse muestra su modelo 3D en pantalla, ofreciendo una experiencia más cercana e interactiva.

El objetivo de este proyecto fue aprender a integrar APIs, manejar estados en React y trabajar con modelos 3D dentro del entorno web.


🧠 Tecnologías utilizadas

⚛️ React – Framework principal para la interfaz.

💻 JavaScript (ES6+) – Lógica e interacción con la API.

🎨 HTML5 & CSS3 – Estructura y estilos de la aplicación.

🔗 PokéAPI – Fuente de datos sobre los Pokémon.

🌀 Three.js o modelos GLTF/GLB (si aplica) – Para renderizar los modelos 3D.



📦 Instalación y ejecución

Clona este repositorio:

git clone https://github.com/tu-usuario/pokemon-3d-cards.git


Entra al directorio del proyecto:

cd pokemon-3d-cards


Instala las dependencias:

npm install


Inicia la aplicación:

npm run dev


o abre tu navegador en http://localhost:5173/
 

 

🌐 Uso

En la página principal verás varias cartas con diferentes Pokémon.

Haz clic en “Invocar” para ver su modelo 3D.

Puedes explorar diferentes criaturas y ver su información básica como tipo, peso y habilidades.
